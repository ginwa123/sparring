Scenario & stacks

  • Seed: 5000 user_{i} rows, /tmp/sparring_sqlite.db per container, WAL + busy_timeout=5000 + synchronous=NORMAL + temp_store=MEMORY.
  • 7 /db/* endpoints: health (SELECT 1), point read, list scan, LIKE search (complex read), insert (201), update, delete ({"deleted":N}). Parity gate: scripts/smoke-db.sh → ALL_PASS on all four.
  • Workloads: sqlite_read = 50/25/25 point/list/search · sqlite_write = 50/50 insert/update · sqlite_mixed = 50/15/10/10/10/5 + deletes (scripts/wrk-sqlite-*.lua).
  • Sandbox: --cpus=2 --memory=512m --memory-swap=512m --pids-limit=512 --ulimit nofile=4096:4096, loopback-only publish. wrk -t4, 10 s, 3 reps, alternating order, 2 s cooldown, host-side.
  • Raw logs: results/wrk_*_sqlite_*.txt + results/wrk_runs_sqlite.log.
